# ☠️ PGFX PromptCrafter for ComfyUI
**The Billion-Dollar Standard in Agentic Content Creation**

ComfyUI-PromptCrafter is an industrial-grade node suite designed for high-scale, professional creative pipelines. It bridges the gap between manual design precision and AI generative power.

---

## 💎 The Crown Jewel: PGFX Logo Designer Studio
The centerpiece of the suite is a **fully integrated Vector Design App** built directly into ComfyUI.

### **✨ Design Studio Highlights**
*   **Prompt-Aware Design Handoff**: The **Logo Designer Agent** translates user intent and reference imagery into Studio settings while staying grounded in the saved design and `design_library.json`.
*   **🧬 Evolutionary Design Library**: The suite features a self-expanding **`design_library.json`**. The AI autonomously discovers and categorizes new materials, motifs, and styles from your prompts and reference images, ranking them by usage.
*   **Fabric.js Canvas Engine**: A high-performance, persistent design workspace for professional manual polish.
*   **Pro Drawing Toolbar**: Free-hand Pencil, Spray, and Circle brushes with live opacity and size controls.
*   **Vector Primitive Library**: Instant generation of Rectangles, Circles, Triangles, Stars, and Hexagons.
*   **Pixel-First Integrity**: Your manual layout serves as the absolute "Source of Truth" for the final render.
